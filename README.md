# 摸鱼签筒 · 生涯占卜

一个单文件、可离线打开的「打工人赛博求签」网页。把"今天要不要摸鱼 / 该不该跑路"这种说不清的心情，变成一支可摇、可存、可分享、可收集的签。

> 它是图一乐的玩具，不是标准化心理量表，未做信效度检验，不做临床诊断或职业建议。

## 玩法

- **摇签**：红漆签筒左右摇晃，飞出一签，弹出签文卡片（不撑开页面布局）。
- **60 支签**：对齐传统"六十甲子"，分 8 档运势（鸿运 / 顺遂 / 安稳 / 小满 / 佛系 / 水逆 / 想跑 / 玄学）。
- **双模式**：自由抽（随机）/ 今日签（同一浏览器同一天结果固定）。
- **集签图鉴**：摇过的签点亮左栏图鉴与进度条，进度存本机。
- **存图转发**：一键生成 750×1420 竖版签文海报（PNG，Canvas 本地绘制），带签号与裂变文案。

## 使用

直接双击 `assets/quiz.html` 即可，零外部依赖、不联网、数据不出本机。
